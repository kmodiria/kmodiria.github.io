Credit Card Default Prediction Model

Machine Learning • 2024

Built an end-to-end ML pipeline to predict credit card defaults using a dataset of 30,000 examples. Performed feature engineering (creating PAY_RATIO metrics), handled class imbalance, and compared four models: Logistic Regression, Random Forest, XGBoost, and Gradient Boosting.

Results: Achieved ROC-AUC of 0.776 with XGBoost after hyperparameter tuning. Used permutation importance and model-based feature importance to identify payment history (PAY_0, PAY_2, PAY_3) as the strongest predictors.
